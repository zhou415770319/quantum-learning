集成学习算法（Ensemble Methods）详解

适用场景速览：任务类型 = 分类 + 回归；核心思想 = 把多个"弱学习器"组合成一个"强学习器"，通常比单一模型更准确、更稳定。本文从原理 → 公式 → 三大代表算法（随机森林 / GBDT / XGBoost / LightGBM）→ 调参与选型 → 面试高频问题，完整讲清这一族算法。

1. 什么是集成学习

定义：不训练一个"超级模型"，而是训练多个相对简单的基学习器（base learner，常称弱学习器），再按某种策略把它们的输出合并，得到一个泛化能力更强的最终模型。

为什么有效（直觉 + 理论）

  • 统计角度：单个模型容易因训练数据噪声产生偏差或方差，多个模型的错误往往不完全相关，投票/平均可以把随机误差抵消掉。
  • 计算角度：把一个难问题拆成许多子问题并行/串行求解，更容易收敛。
  • 表示角度：单一模型的假设空间可能覆盖不了真实函数，多个模型组合能扩大表示范围。

两个关键概念（面试必问）

概念 含义 控制手段
偏差（Bias） 模型本身太简单，拟合不了规律（欠拟合） 提升模型复杂度、Boosting 逐轮纠错
方差（Variance） 模型对数据扰动太敏感（过拟合） 多模型平均、Bagging、加正则

集成学习的两大流派正是分别从这两个角度下手：

                    ┌─ Bagging（并行）：Boost variance ↓ —— 代表：随机森林
集成学习 Ensemble ──┤
                    └─ Boosting（串行）：Boost bias ↓ —— 代表：GBDT / XGBoost / LightGBM

2. Bagging：并行集成（随机森林的基石）

2.1 Bootstrap + Aggregating

  1. 自助采样（Bootstrap）：从 N 条训练数据中有放回地抽 N 条，形成一个新训练集。约 63.2% 的样本会被抽到（1 − e⁻¹ ≈ 0.632），其余 36.8% 称为袋外样本（OOB, Out-of-Bag），可直接当验证集用——这是随机森林的免费福利。
  2. 并行训练：独立训练 T 个基学习器（通常是决策树）。
  3. 聚合（Aggregating）：
  4. 分类：多数投票（majority voting）
  5. 回归：取平均（averaging）

2.2 为什么平均能降方差

设每个基学习器的方差为 σ²，两两相关系数为 ρ，则 T 个模型平均后的方差为：

Var(平均) = ρ·σ² + (1−ρ)/T · σ²
  • T → ∞ 时方差下限是 ρσ²：树之间越不相关（ρ 越小），降方差效果越好。
  • 这正是随机森林第二重随机性的理论依据（见下节）：故意让每棵树只看一部分特征，把 ρ 压低。

3. 随机森林（Random Forest）

3.1 核心机制：双重随机性

随机森林 = Bagging + 决策树 + 特征随机，两层随机保证树与树之间差异够大：

  1. 样本随机：每棵树用 Bootstrap 抽样训练（约 63% 样本，其余作 OOB）。
  2. 特征随机：每个节点分裂时，不再从全部 d 个特征中选最优，而是先随机抽 k = √d 个特征（回归任务常用 k = d/3），只在这 k 个里挑分裂点。

3.2 训练与预测流程

训练：for t = 1..T（可完全并行）:
    ① Bootstrap 抽样得到 D_t
    ② 在 D_t 上训练一棵决策树（节点分裂仅考察随机抽的 √d 个特征）
    ③ 默认树不剪枝，让每棵树充分生长（低偏差高方差，靠平均降方差）

预测：
    分类 → 每棵树投票，取票数最多的类别（或平均类概率）
    回归 → T 棵树输出的算术平均

3.3 为什么抗过拟合能力强

  • 单棵深树方差大，但 T 棵独立噪声平均后方差约降为 1/T（理想情况下）。
  • 特征随机进一步降低树间相关性 ρ，压低方差下限 ρσ²。
  • OOB 样本天然提供泛化估计：OOB 误差 ≈ 每条样本只用没见过它的那些树预测，再取平均错误率，不用单独切验证集。

3.4 附加能力

  • 特征重要性：基于 OOB 的置换重要性（打乱某特征看误差涨多少），或按分裂不纯度下降累计。
  • 天然可并行：树与树完全独立，适合多核/分布式训练。
  • 对缺失值、异常值、量纲不敏感（基于树的分裂与量纲无关）。

3.5 主要超参数

超参数 作用 经验值
n_estimators（T） 树的数量，越大越稳（收益递减） 100–1000，越大越好直到误差平台
max_features（k） 分裂时考察的特征数，越小 → 树越不相关、单树越弱 分类 √d，回归 d/3
max_depth / min_samples_leaf 控制单树复杂度 深度 10–30 或不限制
n_jobs 并行核数 −1 全核

4. Boosting：串行集成（GBDT 家族的基石）

4.1 核心思想

串行训练 T 个弱学习器，每一轮都在"纠正前面所有轮累计犯的错"——把偏差一轮轮磨掉。经典实现是 AdaBoost（调样本权重），工业主流是梯度提升（Gradient Boosting）：把"纠错"统一成在负梯度方向上拟合一个新树。

4.2 梯度提升的数学框架（重要，面试推导点）

设最终模型为 F(x) = Σₘ fₘ(x)（fₘ 是第 m 轮的树），损失函数 L(y, F(x))。前向分步加法模型，第 m 轮求解：

Fₘ(x) = Fₘ₋₁(x) + fₘ(x),\quad fₘ = argmin_f Σᵢ L(yᵢ, Fₘ₋₁(xᵢ) + f(xᵢ))

精确求解太难，用梯度下降的函数空间版本：计算每个样本的伪残差（负梯度）：

rᵢₘ = −[∂L(yᵢ, F(xᵢ)) / ∂F(xᵢ)]_{F=Fₘ₋₁}

然后用一棵回归树 ĥₘ 去拟合 (xᵢ, rᵢₘ)，再把每个叶子节点的输出替换为使损失最小的常数：

γⱼₘ = argmin_γ Σ_{xᵢ ∈ 叶子j} L(yᵢ, Fₘ₋₁(xᵢ) + γ)

最终：Fₘ(x) = Fₘ₋₁(x) + ν · Σⱼ γⱼₘ · I(x ∈ 叶子j)，其中 ν 是学习率（shrinkage），每轮只走一小步。

4.3 各损失函数下的"残差"是什么

任务 损失 L 伪残差 rᵢₘ
回归（平方损失） ½(y − F)² yᵢ − Fₘ₋₁(xᵢ)（真·残差，最直观）
回归（绝对损失/Huber） |y − F| sign(yᵢ − Fₘ₋₁(xᵢ))，对异常值更稳
二分类 log(1 + e^(−2yF))，y ∈ {−1,+1} 4yᵢ / (1 + e^(2yᵢFₘ₋₁)) ≈ 概率残差
排序 LambdaRank 等 文档对的梯度

一句话记忆："每一轮拟合残差" 在平方损失下是字面意思，一般情形是拟合负梯度。

5. GBDT → XGBoost → LightGBM 的演进

5.1 GBDT（经典梯度提升树）

  • CART 回归树做基学习器 + 负梯度拟合 + 学习率收缩。
  • 缺点：只 用一阶梯度；穷举所有分裂点；CPU 单线程为主；对噪声敏感。

5.2 XGBoost：工程化 + 二阶正则化

目标函数在 Fₘ₋₁ 处做二阶泰勒展开（这是 XGBoost 区别于 GBDT 的理论核心）：

Obj ≈ Σᵢ [ gᵢ·fₜ(xᵢ) + ½·hᵢ·fₜ²(xᵢ) ] + Ω(fₜ)

其中 gᵢ = 一阶梯度，hᵢ = 二阶梯度（Hessian），正则项：

Ω(fₜ) = γ·T_leaves + ½·λ·Σⱼ wⱼ²

（T_leaves = 叶子数，wⱼ = 叶子权重 → 同时惩罚叶子数量和叶子权重大小，从结构上防过拟合。）

展开后每个候选分裂的增益公式（面试常要求写出）：

Gain = ½·[ G_L²/(H_L+λ) + G_R²/(H_R+λ) − (G_L+G_R)²/(H_L+H_R+λ) ] − γ

（G/H 为左右子树一阶、二阶梯度之和；增益 < γ 时停止分裂，γ 起预剪枝作用。）

工程特性：列采样（借自随机森林）、缺失值自动学习默认分裂方向、近似分位数切分点算法（weighted quantile sketch）、并行化（特征级并行，非树级）、early stopping。

5.3 LightGBM：为大数据速度而生

  • GOSS（Gradient-based One-Side Sampling）：保留大梯度样本（难样本），随机丢弃小梯度样本并放大其权重 → 少量数据保留精度。
  • EFB（Exclusive Feature Bundling）：把互斥的稀疏特征（如 one-hot）捆绑成一列，降维加速。
  • 直方图算法：把连续特征分桶（默认 255 bins）后按直方图找分裂点，复杂度从 O(#数据×#特征) 降到 O(#数据×#特征常数)，且可用叶子优先（leaf-wise）生长：每次分裂增益最大的叶子，同深度下比 XGBoost 的 level-wise 更准更快，但更深、需用 num_leaves/depth 限制防过拟合。
  • 原生支持类别特征（不需 one-hot）。

5.4 三者对比表（面试高频）

6. Bagging vs Boosting 对比总结

维度 Bagging（随机森林） Boosting（GBDT 系）
训练方式 并行，各树独立 串行，每轮依赖上一轮
优化目标 降方差 降偏差（也会略降方差）
基学习器 强而深、不剪枝的树 弱而浅的树（深度 3–8）
样本使用 Bootstrap 有放回抽样 每轮全量数据（权重/梯度重分配）
抗过拟合 强（靠平均） 靠正则 + 学习率 + early stopping
对噪声/异常值 稳健 敏感（尤其平方损失 GBDT）
超参敏感度 低，默认就很能打 高，需要精调
可并行 树级并行 单树内特征/直方图并行，树间不可
典型用途 快速基线、特征重要性、噪声大数据 竞赛/工业结构化数据刷点

7. 实战选型与调参要点

选型决策

  1. 先跑随机森林当基线：几乎不用调参、并行快、给出特征重要性。
  2. 要精度刷点 → 上 LightGBM（数据量大/类别特征多）或 XGBoost（数据量中等、想要成熟生态）。
  3. 表格数据（结构化数据）上这族算法通常优于深度学习；图像/文本/语音才轮到神经网络。

GBDT 系通用调参顺序（经验）

  1. 固定学习率（如 0.1）+ 适中树数，用 early stopping 定轮数；
  2. 调单树复杂度：max_depth（3–8）/ num_leaves（LightGBM ≤ 2^depth）、min_child_samples；
  3. 调随机性正则：subsample（0.7–0.9）、colsample_bytree（0.7–1.0）；
  4. 调结构正则：reg_lambda（λ）、reg_alpha（α）、min_split_gain（γ）；
  5. 最后降学习率（0.01–0.05）+ 更多轮数精修。

8. 面试高频问答（速背版）

  1. 随机森林为什么抗过拟合？ 双重随机（Bootstrap 样本 + 节点特征抽样）使树间低相关，T 棵独立高方差树平均后方差 ≈ 1/T 量级下降，且 OOB 免费验证。
  2. GBDT 的"残差"是什么？ 平方损失下是真实残差 y − F；一般损失下是负梯度（伪残差），本质是函数空间的梯度下降。
  3. XGBoost 相比 GBDT 的改进？ ① 二阶泰勒展开（牛顿步，收敛更快）；② 显式正则项 Ω = γT + ½λΣw²；③ 列采样、缺失值处理、近似分位分裂、工程并行。
  4. LightGBM 为什么快？ 直方图算法 + GOSS 单侧采样 + EFB 稀疏特征捆绑 + leaf-wise 生长。
  5. Bagging 和 Boosting 分别主要降什么？ Bagging 降方差（模型强而独立），Boosting 降偏差（模型弱而串行纠错）——因此前者配强基学习器、后者配弱基学习器。
  6. GBDT 如何做分类？ 每轮为每个类别训练一棵树拟合负梯度（对数损失），输出经 Softmax 概率化；二分类则拟合对数几率残差。
  7. 为什么树模型不需要特征归一化？ 分裂基于阈值比较，与量纲无关；但 LightGBM 的直方图分桶对极端分布仍可受益于变换（如取 log）。
