## 一、数学基础

### 1. ⭐ 为什么量子演化必须是酉的？

参考答案要点：
- 酉算子 U 满足 U†U = I，保证内积（从而总概率）守恒——这是量子力学概率解释的自洽性要求
- 酉演化可逆：U† 可精确还原初始态，对应封闭系统的可逆性
- 反证：若有非酉演化，概率不守恒，意味着系统与外界有信息交换（实际是开放系统，可用密度矩阵+主方程描述）

### 2. 厄米矩阵有什么性质？在量子力学中扮演什么角色？

- 特征值为实数；不同特征值对应的特征向量正交；可对角化
- 可观测量（哈密顿量）都是厄米算子：测量结果只能是实数，且谱分解给出可能的测量结果集合

### 3. 张量积和普通矩阵乘法有什么区别？为什么量子态要结合成张量积？

- 张量积维度相乘：2⊗2 → 4 维，表示复合系统的联合状态空间；普通乘法不改变空间结构
- 量子系统的联合态 = 各子系统态的张量积（可分离时）；这正是"量子比特数翻倍、状态空间指数增长"的来源
- 关键区分：有些两比特态**不能**写成张量积形式——即纠缠态

### 4. 什么是 Schmidt 分解？有什么用？

- 任意纯态 |ψ⟩ ∈ H_A ⊗ H_B 可写成 |ψ⟩ = Σᵢ λᵢ |uᵢ⟩|vᵢ⟩，λᵢ ≥ 0 且 Σλᵢ² = 1
- 用途：判定纠缠（非零 Schmidt 系数个数 > 1 即纠缠）；非零系数个数称为 Schmidt 秩；是量化纠缠、分析纯态纠缠转换（LOCC）的基础工具

## 二、量子力学基础

### 5. ⭐ 用 Bloch 球描述单量子比特态

- 任意单比特态 |ψ⟩ = cos(θ/2)|0⟩ + e^{iφ} sin(θ/2)|1⟩
- 对应球面上点 (sinθcosφ, sinθsinφ, cosθ)；|0⟩ 是北极、|1⟩ 是南极
- 全局相位 |ψ⟩ 和 e^{iα}|ψ⟩ 物理等价，故两个实参数 (θ, φ) 足够
- 单比特门 = Bloch 球上的旋转（如 Rx(θ) 绕 x 轴转 θ 角）——面试常让你把某个门说成旋转

### 6. ⭐ 解释叠加态。|0⟩+|1⟩ 到底"是"什么？

- 测量前系统处于基态的线性组合，测量以概率 |α|²、|β|² 得到 |0⟩ 或 |1⟩（玻恩规则）
- 正确说法：不是"同时处于 0 和 1"，而是状态空间中的一个合法矢量；测量后才塌缩到基态
- 关键点：量子加速不来自"并行试遍所有答案"（这个说法面试官会追问打假），而来自干涉——错误答案的振幅相消、正确答案的振幅相长

### 7. ⭐ 什么是纠缠？举两个 Bell 态并说明为什么它们纠缠。

- Bell 态例子：|Φ⁺⟩ = (|00⟩+|11⟩)/√2，|Ψ⁻⟩ = (|01⟩−|10⟩)/√2
- 判定：|Φ⁺⟩ 无法写成 |a⟩⊗|b⟩（展开联立方程组会导出矛盾）；测量第一个比特立即完全确定第二个比特的结果，且基底可任选——关联超过任何经典关联
- 补充：纠缠 ≠ 只是经典相关；Bell 不等式（CHSH）实验证明量子关联违反局域实在论，S 最多达 2√2

### 8. 说出 Bell 不等式/CHSH 的含义

- CHSH 量 S = |E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′)|，任何局域隐变量理论 S ≤ 2
- 量子力学可达到 2√2（Tsirelson 界），实验（Aspect 及后续无漏洞实验）支持量子
- 面试意义：纠缠是真实的物理资源，不是"数学巧合"；这是量子密钥分发、设备无关协议的根基

### 9. 不可克隆定理（no-cloning）的内容与证明

- 不存在酉操作能复制任意未知量子态：U|ψ⟩|0⟩ = |ψ⟩|ψ⟩ 对所有 |ψ⟩ 成立
- 证明（线性性）：若对 |ψ⟩、|φ⟩ 都成立，则对 (|ψ⟩+|φ⟩)/√2 左边得叠加态的克隆，右边得纠缠态，两者不相等，矛盾
- 影响：解释了量子通信的安全性基础；也说明量子纠错不能靠"备份"实现

### 10. 纯态与混合态的区别？密度矩阵怎么用？

- 纯态：ρ = |ψ⟩⟨ψ|，Tr(ρ²) = 1；混合态：ρ = Σpᵢ|ψᵢ⟩⟨ψᵢ|，Tr(ρ²) < 1
- 混合态描述经典不确定性（统计混合）或与环境的纠缠（真正的量子混态，如退相干后的状态）
- 用途：开放系统演化、测量统计、保真度计算都离不开密度矩阵

## 三、量子比特与量子门

### 11. ⭐ 写出 H、X、Z、CNOT 的矩阵并说明作用

- X = [[0,1],[1,0]]：比特翻转（Bloch 球绕 x 轴转 π）
- Z = [[1,0],[0,−1]]：相位翻转，|1⟩ → −|1⟩
- H = (1/√2)[[1,1],[1,−1]]：把基态变成等幅叠加；H|0⟩ = |+⟩；且 H² = I（自逆）
- CNOT：控制比特为 1 时翻转目标比特；作用是把 |+⟩⊗|0⟩ 变成 Bell 态（纠缠的"制造机"）

### 12. H、S、T 门和旋转门的关系？

- S = 相位 π/2 门 = Rz? 注意 S = diag(1, i)，相当于绕 z 轴转 π/2（差全局相位）
- T = diag(1, e^{iπ/4})，是绕 z 轴转 π/4
- Cliffford 组 {H, S, CNOT} 单独模拟可高效（Gottesman-Knill 定理）；T 门（非 Clifford）是实现通用量子计算、也是容错计算成本最高的资源

### 13. ⭐ 什么是万能门集（universal gate set）？举例

- 任意 n 比特酉算子都能以任意精度近似的一组门
- 标准答案：{所有单比特门, CNOT}；离散版本：{H, T, CNOT}（Solovay-Kitaev 定理保证近似效率 O(log^c(1/ε))）
- 追问点：{H, S, CNOT} 不是万能的——全在 Clifford 群内，可被经典高效模拟

### 14. 给定电路，如何手动模拟输出？（现场题套路）

- 步骤：写出各门矩阵 → 张量积扩展到全空间 → 按顺序左乘；或按比特跟踪振幅
- 技巧：先用 H 生成叠加，再跟踪 CNOT 如何"搬运"振幅；注意振幅是复数，概率 = |振幅|²
- 常考例题：Bell 态电路（H⊗I + CNOT）、三比特 GHZ 态、隐传（teleportation）电路

### 15. 描述量子隐传（teleportation）协议

- 目标：把未知态 |ψ⟩ 从 Alice 传给 Bob，不物理传输该比特
- 资源：一对纠缠比特（Bell 对）+ 2 经典比特
- 流程：Alice 对 (|ψ⟩, 她的纠缠比特) 做 Bell 基测量 → 得 2 经典比特 → 发给 Bob → Bob 按结果做 I/X/Z/XZ 修正
- 追问：为什么没违反 no-cloning？——原态在测量中被破坏；为什么没超光速？——必须等经典信道

### 16. 受控-U 门怎么构造？U 任意给定时

- 定义：|00⟩→|00⟩, |10⟩→|1⟩U|0⟩ 之类（控制为 1 时对目标施加 U）
- 对单比特 U：可用 2 个 CNOT + 单比特旋转精确构造（标准分解）
- 高频考点：Toffoli（CCNOT）不是原始门时如何用单/双比特门 + 辅助比特实现

## 四、核心算法（重中之重）

### 17. ⭐ 完整推导 Deutsch-Jozsa 算法

- 问题：黑盒函数 f，承诺是常数或平衡，判断是哪种
- 流程：n+1 比特全置于 |+⟩⊗...⊗|−⟩ → 每个输入比特过 H → 查询一次 U_f → 再过 H → 测量
- 关键相位反冲（phase kickback）：U_f 把 (−1)^{f(x)} 写进振幅符号
- 结果：全 0 → 常数；否则 → 平衡。经典最坏 2^{n−1}+1 次查询，量子 1 次
- 面试要点：能讲清"干涉让错误答案相消"这层直觉，而不只是背流程

### 18. ⭐ 推导 Grover 算法，包括迭代次数

- 目标：N 个无结构项中找标记项，oracle O_f 把 |x⟩ → (−1)^{f(x)}|x⟩
- 两个算子：Oracle（标记态翻转相位）+ 扩散算子 D = 2|s⟩⟨s| − I（绕平均值的反射）
- 几何直觉：初态 |s⟩ 与解子空间夹角 θ，sinθ = √(M/N)；每轮旋转 2θ；约 π/(4θ) ≈ (√N/4)·(π/2) 轮后转到解上
- 成功概率 ≈ 1 时迭代次数 R ≈ π√N/(4√M)，这就是 O(√N) 二次加速
- 追问：最优性——BBBV 证明无结构搜索 √N 是量子下界，不能更快

### 19. ⭐ QPE（量子相位估计）的完整流程与误差分析

- 问题：U|u⟩ = e^{2πiφ}|u⟩，估计 φ
- 流程：t 个计数比特置 |+⟩、目标置 |u⟩ → 受控-U^{2^k}（相位反冲写入 φ）→ 逆 QFT → 测量得 φ 的 t 比特近似
- 精度：t = n + p 个比特时，以 ≥ 1−ε 概率得到 p 位精度的 φ（再加圆整）
- 地位：Shor 的周期查找 = QPE 的特例；量子化学基态能量 = QPE 应用
- 追问：为什么用逆 QFT？——计数比特态是 φ 的傅里叶编码，逆变换解出二进制表示

### 20. ⭐ 从 QFT 到 Shor：讲清整条链

- 分解 N：找 a 与 N 互质，求 f(x) = aˣ mod N 的周期 r（Shor 归约：随机 a，gcd 有概率直接命中；否则 r 偶且 a^{r/2} ≢ −1 时 gcd(a^{r/2}±1, N) 给出因子）
- 周期查找 = 相位估计 U|1⟩ = (1/√r)Σe^{2πik/r}|a^k mod N⟩（本征相位 φ = k/r）
- 测量得接近 s/r 的分数 → 连分数展开恢复 r（需 r < N，成功概率常数级，重试几次）
- QFT 定义：|x⟩ → (1/√N)Σ_y e^{2πixy/N}|y⟩，只用 O(n²) 个门，是指数级加速的核心
- 总结句式："Shor = 把分解归约为周期查找，把周期查找归约为 QPE，QPE 归约为 QFT"

### 21. VQE 是什么？和 QPE 什么关系？

- 变分量子本征求解器：NISQ 时代的基态能量算法
- 结构：参数化量子电路 U(θ)（ansatz）制备试探态 → 测量 ⟨ψ(θ)|H|ψ(θ)⟩ → 经典优化器更新 θ → 瑞利商下界（变分原理）保证收敛到基态能量
- 对比：QPE 精度高但需要长深度电路+纠错；VQE 浅电路、有噪声但今天能跑
- 追问：ansatz 选择（UCCSD、硬件高效 ansatz）、贫瘠高原（barren plateau）问题

### 22. QAOA 的思路？

- 组合优化（如 MaxCut）：cost 哈密顿量 H_C 与 mixer 哈密顿量 H_M 交替演化
- 状态：|γ,β⟩ = e^{−iβ_p H_M} e^{−iγ_p H_C} ... |+⟩^n，p 层参数用经典优化器调
- p → ∞ 时收敛到精确解；p 小时是启发式，性能依赖参数优化
- 面试常问：与 VQE 的区别（VQE 求 energies，QAOA 近似 combinatorial 最优；结构上都是变分+经典外环）

## 五、噪声与量子纠错

### 23. ⭐ T1 和 T2 分别是什么？

- T1（弛豫时间）：|1⟩ 衰变到 |0⟩ 的能量耗散时间常数
- T2（退相干时间）：叠加态相位信息丢失的时间；且 T2 ≤ 2·T1
- 面试要点：能解释 T2 中同时含能量弛豫（T1 贡献）和纯退相干（T_φ）两部分：1/T2 = 1/(2T1) + 1/T_φ

### 24. 退相干在密度矩阵里怎么表现？

- 纯态 ρ = |ψ⟩⟨ψ| 的非对角项（相干项）随时间衰减：ρ₀₁(t) = ρ₀₁(0)·e^{−t/T2}
- 对角项（布居）按 T1 衰减；相干性消失后变成经典混合态
- 直觉：环境"测量"了系统，把叠加泄露成纠缠——这就是量子纠错必须对抗的东西

### 25. ⭐ 三比特比特翻转码怎么工作？它为什么还不够？

- 编码：|0⟩→|000⟩，|1⟩→|111⟩（不能复制态本身，用基态编码规避 no-cloning）
- 纠错：用辅助比特做奇偶校验（测 Z₁Z₂、Z₂Z₃），定位出错比特后用 X 修正
- 局限：只纠 X 错误；相位错误（Z）完全防护不了
- 追问：Shor 九比特码同时纠 X 和 Z（把三比特码做两层）；CSS 码是 generalization

### 26. ⭐ 表面码（surface code）为什么是主流路线？

- 二维晶格上的拓扑码：数据比特在边、测量比特在面/点，只需**近邻**相互作用——匹配超导芯片的平面工艺
- 阈值约 1%（物理错误率低于阈值时，增大码距 d 指数级压低逻辑错误率）
- 逻辑错误率 ~ (p/p_th)^{(d+1)/2}；码距 d 用 2d²−1 个物理比特
- 追问：表面码每逻辑比特需要上千物理比特（开销大）；qLDPC 码是降低开销的新方向（IBM 2024 路线）

### 27. 阈值定理说了什么？为什么它给量子计算可行性定了性？

- 只要物理门错误率低于某阈值（表面码 ~1%），就可以用可扩展的纠错让逻辑错误率任意低，额外开销只多项式增长
- 意义：证明噪声不是原理性障碍——"量子计算可以扩展"的理论基石
- 现实补充：阈值定理假设错误局部、独立、可并行纠错；相关噪声（cosmic ray 事件）仍是工程挑战

### 28. 逻辑量子比特 vs 物理量子比特？现在进展如何（截至 2025-2026）？

- 物理比特：硬件上真实的量子系统；逻辑比特：多个物理比特经纠错编码后的可靠单元
- 里程碑：Google Willow（2024）演示码距增大逻辑错误率指数下降（below threshold）；Harvard/QuEra 中性原子 48 逻辑比特演示；IBM 计划 2029 星际之门路线（qLDPC + Starling）
- 面试意义：能聊"从 NISQ 到 FTQC（容错量子计算）的过渡"体现知识更新度

## 六、硬件与工程

### 29. ⭐ 对比超导、离子阱、中性原子、光量子的优缺点

| 路线 | 优点 | 缺点 |
|------|------|------|
| 超导（IBM/Google） | 门快（ns 级）、半导体工艺兼容、已上千比特 | 需 mK 极低温、比特间连接受限、相干时间 ~100μs |
| 离子阱（IonQ/Quantinuum） | 相干时间长、全连接、门保真度最高（>99.9%） | 门慢（μs-ms 级）、扩展需离子输运/模块化 |
| 中性原子（QuEra/原子计算） | 天然可扩展到千比特、可重构连接 | 原子丢失、门速度中等 |
| 光量子（Xanadu/玻色采样） | 室温运行、天然联网 | 双比特门难、概率性门、量子优势限于特定采样问题 |

- 加分点：提一下拓扑量子比特（Microsoft Majorana，2025 有 Majorana 1 芯片发布，但学术验证仍有争议）

### 30. 为什么超导量子比特需要稀释制冷机？

- 约瑟夫森结电路的超导态要求温度远低于超导能隙对应温度，工作在 ~10-20 mK
- 更根本：kT 必须远小于比特能级间隔（~5 GHz ≈ 240 mK），否则热激发破坏量子性
- 工程细节：微波控制线需多层衰减与滤波，防热噪声沿线路渗入

### 31. 用 Qiskit 实现一个 Bell 态（现场手写）

```python
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)
qc.h(0)            # 制备叠加
qc.cx(0, 1)        # 纠缠成 Bell 态
qc.measure([0, 1], [0, 1])

sim = AerSimulator()
result = sim.run(qc, shots=1024).result()
print(result.get_counts())   # 约 '00':512, '11':512，无 '01'/'10'
```

- 要讲清的点：H 之后两比特处于 |+0⟩；CNOT 把 |00⟩ 和 |10⟩ 分别映射为 |00⟩ 和 |11⟩ → (|00⟩+|11⟩)/√2
- 结果只有 00/11 且各半 = 纠缠的直接证据

### 32. 你怎么看量子计算的落地时间线？（开放题，考判断力）

参考框架（结构化作答，别拍脑袋）：
- 已有商用价值探索：量子启发优化、量子退火、QKD 通信（京沪干线）
- 3-5 年：早期容错原型（Google/IBM 路线图），化学模拟小分子可能率先出实用价值
- 10 年+：通用容错量子计算机，Shor 级应用（破解 RSA）需要百万级物理比特
- 关键不确定性：纠错开销能否压下来（qLDPC）、新物理路线（拓扑比特）是否成熟
- 加分收尾："所以现在的后量子密码（PQC）迁移不是超前，是必要"——顺带展示你知道 NIST 2024 年已标准化 ML-KEM 等 PQC 算法
