本源量子云 OriginQ

本源量子 · 合肥
真机 180 比特 4 类模拟器 免费体验入口

国内最完整的“一站式”量子计算云服务平台之一：从真机算力、模拟器到编程框架、课程比赛全覆盖。

  • 真机：“本源悟空 180”第四代自主超导量子计算机（251 个耦合比特），面向全球开放真实算力
  • 模拟器：全振幅 / 含噪声 / 部分振幅 / 单振幅四类量子虚拟机，按精度与内存需求自选
  • 三类云服务：量子计算云、量超智融合云、专用量子云平台（定制化搭建）
  • 软件生态：QPanda（编程框架）、VQNet（量子机器学习）、pyqpanda-algorithm（算法包）、Qurator（插件）、本源司南（量子计算机操作系统）
  • 开发体验：图形化编程工具 + 在线编程 + 任务提交；学习路径课程、量子计算大赛、教研一体化产品
适合：零基础入门 → 算法开发 → 教学科研 官网 →

“天衍”量子计算云平台

中电信量子集团
双路线真机 量子优越性开放

全国唯一同时提供超导 + 光量子两条“量子优越性”路线的云平台，超量混合架构对接天翼云超算。

  • 真机集群：6 台接入（天衍-287、176-I/II、504、24 超导 + 光量子 P2000）；天衍-287 为“祖冲之三号”同款芯片，105 数据 + 182 耦合比特，单比特门保真度 >99.9%
  • 光量子：P2000 属“九章四号”同系列，实现 2682 光子制备与探测，开放线上采样优越性服务
  • 仿真与编程：5 类高性能仿真机 + 自研开源 Cqlib 框架（编译性能较主流提升约 40%）
  • 零代码应用：QAOA 计算框架（问题建模 → 参数 → 可视化一站式）；AI 量子编程助手 Tianyan QMind
  • 生态：2025-04 入驻国家超算互联网；公开报道访问量超 5000 万次、任务超 450 万项，覆盖 60+ 国家
适合：科研验证 / 行业应用（金融、气象、化学） 官网 →

华为 HiQ 量子计算云平台

华为云
模拟器为主 实名免费体验

不主打真机，而是把量子算法开发环境和大规模模拟器搬到云上，适合“先学软件再碰硬件”。

  • 模拟器：全振幅、单振幅、纠错电路模拟三类分布式模拟云服务
  • HiQ Composer：图形化量子线路编程，支持 OpenQASM 与 MindSpore Quantum 线路互转、变分线路构建、实时显示哈密顿量期望值与密度矩阵
  • 开发环境：Jupyter Notebook + 预装 HiQ Fermion / HiQ Pulse / MindQuantum 的 Cloud IDE，可直连 Gitee
  • 应用方向：量子电路仿真、量子化学模拟、量子脉冲模拟；用于算法验证与教学普及
适合：算法原型 / 教学 / 无真机条件的开发者 官网 →

Quafu 量子云算力集群

北京量子院 + 中科院物理所 + 清华
多档免费真机 邮箱注册即用

学术界开放的代表：免费提供多档超导真机，科研与教学都能直接上机。

  • 真机档位：3 / 10 / 11 / 105 / 119 / 136 比特等多种后端
  • 编程：Python API（config 选后端、send 提交任务）+ OpenQASM；支持异步模式按实验 ID 读结果
  • 门槛：邮箱注册即可登录，另有游客访问模式
适合：学生上手真机 / 科研实验 官网 →

百度量子平台（量易伏 / 量桨 / 量脉）

百度
服务状态以官网为准

“量羲”软硬一体化方案的三件套：量子设施即服务（QaaS）+ 量子机器学习 + 脉冲级控制。

  • 量易伏 QCompute：云原生量子计算平台，接入“乾始”超导真机及中科院物理所、精密测量院设备；支持超导 / 离子阱、Q# / Qiskit 等接口
  • 量桨 Paddle Quantum：基于飞桨的量子机器学习平台，支持量子神经网络训练、MBQC 模块，可连接量易伏调用云端算力
  • 量脉 Quanlse：脉冲云计算服务，芯片表征、门标定、误差表征与噪声缓释
  • 其他：QMobile 移动端、量子领域大模型与量子助手
  • 注意：2024-01 百度宣布量子实验室及可移交设备赠予北京量子院，平台当前开放状态请以官网公告为准
适合：量子机器学习 / 脉冲控制研究 资料页 →

“五岳纪元”量子计算云平台

中国移动
多路线 2000+ 比特 偏政企科研

主打“多技术路线统一并网 + 通量一体”，把量子算力做成类似通信的基础设施。

  • 并网规模：超 2000 量子比特，覆盖超导、离子阱、中性原子、相干光、金刚石色心五类路线
  • 软件栈：可视化量子工具链；开源量子计算操作系统 WuYueOS（与中科酷原发布 WuYueOS Inside）；联合开源“观象”量子纠错算法
  • 节点：2026-01 西部（绵阳）节点建成，最高 2001 比特供给，数据本地存储、低时延，提供定制化算法服务
  • 场景：金融、交通、气象、教育、AI、低空经济航线优化、应急通信加密
适合：政企 / 科研 / 区域算力节点 生态社区 →
