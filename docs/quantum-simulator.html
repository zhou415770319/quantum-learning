01 / 动手玩

拖不动也没关系，点两下就能搭电路

先选门，再点电路格子放置；双比特门（CNOT / CZ / SWAP）要点两次：第一次点控制位，第二次点目标位。

① 量子比特数

比特越多，状态空间越大（2ⁿ 个振幅），这里限制 4 比特保证浏览器流畅。

② 选一个门

单比特门点一次放置；CNOT / CZ / SWAP 点两次指定控制位与目标位；橡皮擦点一次删除。

③ 电路（点格子放门）

提示：电路改动后会自动重新计算。

04 / 落地路线

从页面模拟到量子云平台，分三步走

不要一上来就接真机。先把"浏览器算得动"做扎实，后端与真机是后面的事。

阶段一：纯前端（静态站即可）

用本页这种 JS 态矢内核，或引入 quantum-circuit / QuantumJS。电路编辑、振幅、概率、Bloch 球、shots 全在浏览器完成。GitHub Pages 免费托管，零运维。

阶段二：加服务层

Python 服务接 Qiskit Aer，提供 /submit、/result、/backends 三个接口；加用户、限流、任务队列与结果缓存。前端把"重计算"交给后端，比特数上到 30+。

阶段三：接真机与多后端

按平台 API 接入本源 QPanda、天衍、IBM Quantum 等；统一电路 IR（OpenQASM 3）与后端抽象层，处理校准数据、拓扑映射、排队与噪声对比。

关键判断：你的学习站停在阶段一就够了。
  • 教学演示 3~5 比特足够，浏览器算得飞快，还不需要账号体系；
  • 真机接入涉及 API Key、排队、校准数据，且国内平台多数要申请权限，不适合放在公开学习站；
  • 如果以后要做成产品，"前端编辑器 + 统一 QASM IR + 可插拔后端"这套结构可以直接复用，不用重写。
